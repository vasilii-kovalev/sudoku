# Sudoku

## Description

A [Sudoku game](https://en.wikipedia.org/wiki/Sudoku) (9 × 9 cells) built with HTML, CSS and TypeScript.
Uses Vite's vanilla TypeScript setup, with no UI framework or backend.
Puzzles are generated by [SudokuGen](https://github.com/petewritescode/sudoku-gen).

## Features

- Provides several difficulty levels:
  - Easy
  - Medium
  - Hard
  - Expert
- Saves the current puzzle, entries, and selected difficulty in browser storage
- Shares the saved game across tabs and windows using the same browser storage
- Asks for confirmation before discarding entries when generating or resetting a board
- Supports light and dark color schemes
- Supports responsiveness
- Supports offline use after the application files have been cached
- Supports installation through the browser's Progressive Web App (PWA) interface
- Uses light and dark variants of the favicon and installation icons

Why the repository is arranged this way is in [`docs/architecture.md`](./docs/architecture.md).

## Installation

### Node.js and npm

The root `package.json` `devEngines` field requires:

- Node.js `^22.22.2 || ^24.15.0 || >=26.0.0`
- npm `^12.0.0`

Incompatible versions fail at install.

### Setup

From the repository root, run the following commands to install dependencies:

```sh
npm ci
```
